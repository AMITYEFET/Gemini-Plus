Power-up Breakdown

Crafted for Advanced AI Workflows

We inspected every detail of Gemini’s native UI to patch up missing features, giving developers and power users the workspace they deserve.

Native Line Numbers

Adds accurate line numbering to code blocks in both Chat and Gemini Canvas, making debugging and structure analysis seamless.

Canvas Resizer

Integrated toolbar inside the Canvas UI to test your code in different resolutions (Desktop, Tablet, Mobile, or Custom Width limits).

Custom Scrollbars

Fully customizable scrollbar colors. Tweak, theme, or color-pick scrollbars to fit perfectly with dark and light IDE configurations.

Word Wrap

Toggle word wrapping for long code blocks to prevent exhausting horizontal scrolling and read code naturally in one viewport.

Go To Line

Navigate directly to any line in your canvas code. Instantly jump to specific logic blocks inside large scripts or schemas.

Clear Canvas

Add an integrated clean-sweep button to empty all of your canvas workspace code instantly, freeing you up to paste new targets.

Download Code

Save canvas codes directly down to native local files complete with appropriate extensions, like `.js`, `.py`, `.json`, `.css` and more.

Wide Chat Mode

Expands Gemini's narrow conversation layout up to 90% wide view limits, providing room to read larger tables, structural lists and scripts.

Hide Disclaimer

Removes Gemini's bottom legal disclaimer/advice notice permanently to maximize layout spaces and decrease visual distraction.

Interface Language

Force override Gemini's visual interface language to your native preference directly from the settings, bypassing location triggers.

Backup Extension Settings

Export and import your entire Gemini+ extension configuration into a single JSON file to sync your customized layout and styling preferences perfectly across devices.

100% Privacy Safe

Complies fully with modern Chrome Manifest V3 regulations. Gemini+ requires no central servers, ensuring user privacy is preserved.

Install Process

Set Up in Less Than 60 Seconds

Since Gemini+ is a specialized developer tool hosted on GitHub, you can load it instantly into any Chromium browser (Chrome, Brave, Edge, Opera).

1

Get the Package Archive

Download the repository directly as a ZIP file containing the popup interface, stylesheet updates, and safe background processes.

Download ZIP (Stable)
2

Extract the Files

Unpack the downloaded `.zip` file into a dedicated folder on your local machine.

3

Enable Developer Mode in Browser

Open a new tab and navigate to the browser’s extensions controller page.

chrome://extensions

Simply turn on the Developer mode switch in the top-right corner of that page.

4

Load the Folder

Click the "Load unpacked" button in the top-left area. Select the extracted folder containing the extension files.

🎉 Setup Complete! Pin Gemini+ from your extension bar, load up gemini.google.com, and enjoy an enhanced premium AI workspace instantly!

Designed for Security & Privacy

Unlike standard extensions that mine background data or inject script trackers, Gemini+ operates strictly in memory. It holds zero cookies, transmits no personal intelligence outside of checking for official update revisions, and is fully audit-ready.

Strict Chrome Manifest V3 Compliance

Built atop Chrome's latest security guidelines to ensure your system memory is fully guarded.

No Server Backend

All preferences, backup states, and settings reside in your browser's private Chrome Sync database.
